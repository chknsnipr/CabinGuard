# CabinGuard
the Scripts to shooter Game built by me.

Basically in this game you have to fend of 4 waves of enemies to win. Your stuck at a cabin with most of your allies dead while the others rest. You can even find the remains of fallen allies, a quirk which i will change/update later on to make a cool easter egg. Took long hours of work and my first fully built unity project.

On how to play it; You install the game from github, and run through the file silenttry.
